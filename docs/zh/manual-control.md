# 手动直控（虚拟键鼠）

> [返回索引](index.md) · [项目简介](../../README.zh.md)

点顶栏的 **直控** 按钮后：

- **手势**：非直控状态下双击屏幕弹出键鼠面板，上滑屏幕打开日志；
- **触屏**：直接在屏幕画面上点按 = 左键，快速双击 = 双击，按住拖动 = 鼠标拖拽，滚轮/双指滑动 = 滚动；
- **虚拟鼠标**：鼠标与键盘同屏显示；触摸板采用**相对位移**（手指移动按比例
  移动光标，不跳变），支持轻点/双击/长按右键/拖动，并附左键、双击、右键、
  滚动按钮；
- **虚拟键盘**：提供字母数字、Shift/Ctrl/Alt/Win 组合键、方向键、回车、
  退格、Tab、Esc、空格。

面板顶部有**折叠/展开**按钮，鼠标区和键盘区也可单独收起；两区之间的
分割线可拖动调整鼠标区高度，面板最上沿的虚线把手可拖动调整整个面板
高度（键盘区随之伸缩），方便小屏手机上保留可视画面。

这些事件经 `/ws/control` 的 `manual_input` 直接落到键鼠后端，完全不经过
模型；若 Agent 任务正在运行，第一次手动操作会请求其退出，实现打断与接管。
