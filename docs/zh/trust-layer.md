# 信任层：动作预览与隐私遮罩

> [返回索引](index.md) · [项目简介](../../README.zh.md)

Geass 在 PWA 顶栏提供“信任”面板，用来控制两件事：Agent 的动作如何可视化与
审核，以及屏幕隐私遮罩是否生效。设置保存在 `~/.geass/.trust.json` 与
`~/.geass/.masks.json`（均为 0600）。

## 动作预览模式

| 模式 | 行为 |
| --- | --- |
| **智能**（默认） | 所有 GUI 操作在屏幕上显示幽灵标注，延迟默认 600ms 后自动执行；终端命令、关闭终端、首次使用的 MCP 工具会等待手机确认 |
| **全部确认** | 每个可预览动作都在屏幕上等待“执行 / 修改 / 拒绝” |
| **全部放行** | 不显示预览也不等待，仅保留原有终端黑名单审核 |

- 可视化内容：鼠标移动到目标的十字光圈、点击/双击/右键光圈、拖拽箭头与双端手柄、滚动方向、
  文本气泡，以及“步骤 3/7 · 点击「保存」· 自动执行 0.6s”状态条。
- 智能模式下状态条带“拦截”按钮，可在延迟结束前中止当前动作。
- 全部确认模式可修改目标：point/drag 可直接在画面上拖拽标记，文本/命令/按键/
  URL 可在卡片里编辑，滚动可调整步数。
- 确认卡片提供“始终允许该工具”“本任务全部放行”；工具覆盖写入可信设置，
  黑名单高危命令无法被静默放行。
- 没有手机控制端在线时，需要确认的动作直接拒绝；智能模式下的 GUI 动作仍会
  在延迟后执行。

## 隐私遮罩

- 默认**关闭**；在“信任 → 隐私遮罩”里打开总开关，或首次框选区域后自动开启。
- 点击“框选遮罩区域”后在画面拖动即可添加；遮罩只在开启时显示半透明框，
  关闭总开关后画面不再显示遮罩框（位置仍可在面板列表里查看）。
- 取消方式：点“取消框选”或按 Esc 退出框选（添加一个区域后会自动退出）；
  单个区域用“删除”，全部取消用“清空全部遮罩”；关闭总开关后画面不再显示遮罩框。
- 遮罩在服务端截图出口生效，因此实时推流、发给模型的截图、OCR 与动作前后帧
  全部自动打码；只覆盖主屏，且不阻止点击（交互拦截由动作预览负责）。
- 最多 20 个区域，单边最小 1%；删除可直接在面板中完成。
- **自动识别**：点“自动识别敏感区域”会运行一次识别——AT-SPI 密码/受保护输入框
  ＋ OCR 关键词（密码、验证码、身份证、银行卡、token 等），返回建议区域，可
  逐个“应用”或“全部应用”。它不会自动打码，可能在自绘界面/未配置 OCR Token
  时漏检，仍建议配合手动框选。

## 接口

- `GET/POST /api/trust`：读取/修改模式、可视化延迟、工具覆盖与任务放行；
- `GET /api/privacy/masks`：读取遮罩与总开关；
- `/ws/control`：`action_proposal` / `action_decision` / `action_resolved` /
  `privacy_masks_changed` / `trust_changed`。

本阶段不包含一键撤销与会话回放。
