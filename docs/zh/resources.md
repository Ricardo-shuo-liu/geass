# 资源管理（手机端）

> [返回索引](index.md) · [项目简介](../../README.zh.md)

手机端顶栏的 **资源** 按钮打开资源管理面板，可直接管理 Agent 使用的全部
运行时资产：

- **记忆**：查看条目、删除单条、清空全部；
- **RAG**：添加/删除数据源、启用/停用、重建索引；
- **技能**：查看运行时 SKILL（标注系统/进化）、删除；
- **POT**：查看 Global-COT、ROT 启用/停用/删除；
- **定时**：查看待执行任务并取消；
- **后台**：查看后台任务（等待/执行/完成/失败）、启动、取消、删除。

所有操作都只作用于运行时数据（`~/.geass/`），不会修改原始文件；删除
系统技能会在下次同步时从种子目录恢复。

后端接口：`GET/POST/DELETE /api/resources/...`（详情见
[DESIGN.md](../DESIGN.md)），与 CLI 命令共享同一套存储。
