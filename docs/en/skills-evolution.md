# Skill evolution & runtime directory

> [Back to index](index.md) · [Project overview](../../README.md)

SKILLs are no longer read directly from the repository. `skills/` is just a
seed directory that is synced into `~/.geass/.skill/.system/` at startup and
before each command; the Agent actually loads from `~/.geass/.skill/` (`~` is
the user home, alongside `~/.geass/env.toml` and `~/.geass/.memory`). The root
can be changed with `agent.skill_root`.

```text
~/.geass/.skill/
  .system/        # system skills synced from the repo skills/ folder
  <evolved-name>/ # skills generated by idle evolution
  .evolution/     # task history and evolution logs (tasks.jsonl / history.jsonl)
```

A background evolution engine waits until `agent.evolution_idle_seconds`
(300s by default) has passed with no command received and no task running,
then sends persistent memory plus recent task history to the model. The model
decides whether a new low-level, general-purpose SKILL is justified and, if so,
the result is written to `~/.geass/.skill/<name>/SKILL.md` and becomes available on the
next command. Runs are spaced by `agent.evolution_interval` (1800s default)
and capped at `agent.evolution_max_skills` (20 default) generated skills.
